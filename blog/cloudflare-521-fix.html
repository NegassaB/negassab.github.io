The 521 That Wouldn't Die: How I Saved My Django API

Published July 16, 2026

Yesterday, my production API went dark with the dreaded Cloudflare Error 521. Here is how I crushed the bot attack suffocating my server.

The Mystery

My PWA was working, but the API was timing out. Using curl, I confirmed the server was dropping packets.

The Solution


# Cloudflare WAF Rule
(lower(http.request.uri.path) contains ".php") or 
(http.request.uri.path contains ".env")

Blocking .php requests at the edge dropped server load by 80% instantly. I then configured Nginx to see real IPs using real_ip_header CF-Connecting-IP; so Fail2Ban could do its job.
